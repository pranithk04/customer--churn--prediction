# Customer Churn Prediction 📊

An end-to-end Machine Learning classification project designed to predict customer attrition based on service usage, tenure, and account activity patterns.

## 🚀 Key Features
- **Data Generation & Preprocessing:** Synthetic dataset setup simulating real-world telecom customer metrics.
- **Model Training:** Built using a `RandomForestClassifier` for high accuracy on tabular data.
- **Performance Metrics:** Evaluated using accuracy, precision, recall, and F1-score via Scikit-Learn.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-learn
